M5Stack xDripMon v2.0.7 (2026-07-30)

- LED strip can now use Grove Port A: the pin setting cycles through
  15 internal / 21 Port A / 26 Port B / 17 Port C (on Core2 the Port A
  option is pin 32, matching its connector). Port A is the only Grove
  port on a Basic without an M5GO bottom.
- Settings are now written to flash the moment a value is confirmed,
  not only when leaving the menu - a reset or power cut with the menu
  still open no longer loses changes (reported as "LED mode does not
  save"). If a flash write ever fails, the log page now shows
  "config save FAILED" instead of losing settings silently.
- Mi Band time sync implemented (Current Time characteristic): if the
  connected app writes the time, the clock is set automatically. Note
  that current xDrip+ (Android) never sends the time over the Mi Band
  protocol, so in xDrip (Android) mode the clock must still be set once
  in Menu -> Set time (Core2 keeps it across power cycles via its RTC;
  Basic/Fire keep it only while powered). xDrip4iOS sets the clock
  automatically as before.

M5Stack xDripMon v2.0.6 (2026-07-30)

- RGB LED strip support, ported from M5_NightscoutMon. An external
  WS2812/NeoPixel strip (Grove Port B or C) or the Fire's built-in LED
  bars can flash with the alarm sounds, light red/amber while a warning
  or alarm is active, or stay lit following the glucose colour (green /
  amber / red per the colour thresholds, dim grey when the data is
  stale). Configured entirely on the device in the new
  Menu -> LED strip page (mode, pin, LED count, brightness, test);
  default is off. A colour sweep at power-on doubles as a self-test.

M5Stack xDripMon v2.0.5 (2026-07-19)

- xDrip (Android) setup QR code. When xDrip is chosen at first boot, the
  device now shows a QR code; scanning it in xDrip+ (Settings -> Scan QR to
  load settings) enables Mi Band, clears any stale stored device MAC, and
  sets readings to be sent as notifications - so pairing works in one step
  with no manual settings hunting. The QR stays up until you press the right
  button or xDrip connects. Also available any time under
  Bluetooth -> xDrip setup QR.

M5Stack xDripMon v2.0.4 (2026-07-19)

- xDrip4iOS reconnection watchdog. The iPhone can drift out of Bluetooth
  range without a clean disconnect, leaving the link silent so the device
  never reconnected on its own (unlike xDrip Android, which reconnects
  instantly). Now, in xDrip4iOS mode the device: sends a heartbeat to wake
  the app when no reading arrives for ~6 minutes; forces a reconnect if the
  link stays silent for ~11 minutes; and re-arms advertising if it ever
  stops while disconnected. xDrip (Android) mode is unchanged.

M5Stack xDripMon v2.0.3 (2026-07-18)

- Factory reset now really clears everything: the data source (xDrip /
  xDrip4iOS) and all other settings are reset to defaults, and the device
  asks for the data source again on the next boot. Previously the settings
  were re-saved during the restart and survived the reset.
- README documents how the clock behaves across a reset per core and data
  source (Core2 keeps it via RTC; Basic/Fire lose it and rely on xDrip4iOS
  re-sync or manual re-entry in xDrip Android mode).

M5Stack xDripMon v2.0.2 (2026-07-18)

- First boot (and after a factory reset) now asks which data source to
  use: press A for xDrip (Android) or C for xDrip4iOS. The choice is
  saved; it is no longer silently defaulted.
- Boot screen shows both supported apps: "xDrip" (red) and
  "xDrip4iOS" (blue).
- Authentication is now shown by the Bluetooth icon instead of a text
  line that covered the button hints:
    blinking red  = not connected
    blinking blue = connected, authenticating
    steady blue   = connected and authenticated

M5Stack xDripMon v2.0.1 (2026-07-18)

- Bluetooth icon now shows the connection state: blue = connected,
  blinking red = not connected (status text removed).
- Button hints above the three buttons on all pages and in the menu
  (icons switch to - / ok / + while editing a value).
- New log page (4th page): connections, authentication, readings,
  time sync, alarms.
- App naming updated to "xDrip" (Android) everywhere on the device.

M5Stack xDripMon v2.0.0 (2026-07-18)

Complete rewrite - Bluetooth only, no Wi-Fi, no web server.

- NightscoutMon-style interface: main page (big value, trend arrow,
  mini-graph), big-glucose page, analog clock page.
- High/low alarms with yellow/red thresholds, warning/alarm sounds,
  snooze (middle button).
- On-device configuration menu (hold the middle button): data source,
  units, thresholds, alarms, brightness, rotation, time, Bluetooth.
- Two selectable data sources: xDrip (Android) and xDrip4iOS.
- NimBLE Bluetooth stack (replaces the old Bluedroid stack that limited
  updates to every 10 minutes).

For 16MB ESP32 M5Stack: Basic 16MB / v2.7, Fire, and all Core2.
